🛡️ 1) Dungeon Chase: Where Survival Meets Destruction! ⚔️ (2026)
Excited to showcase Dungeon Chase — a 3D Endless Runner developed in Unreal Engine 5.3! 🎮🏰
This project challenged us to bridge the gap between technical logic and immersive art. While we focused on high-speed mechanics and atmosphere, the true standout feature is our unique Power Mode Mechanic.
💥 The Standout Feature: Power Mode
Unlike traditional runners where you only dodge, in Dungeon Chase, you fight back. By collecting 50 daggers, the player triggers an intense 15-second Power Mode. During this window, the gameplay flips: you stop evading and start smashing, gaining the ability to destroy blocker obstacles that would otherwise end your run. This adds a layer of strategy and high-stakes reward that keeps players pushing for that next dagger.
Core Technical Highlights:
✨ Procedural World Generation: A modular tile-spawning system that ensures a unique dungeon path every time.
✨ Technical Character Integration: Mastered IK Retargeting to bring a custom Viking model to life with fluid movement.
✨ Dynamic HUD: A frame-independent UI progress bar that tracks Power Mode duration in real-time.
Building Dungeon Chase was an incredible hands-on experience in problem-solving and teamwork. From mastering the dark dungeon atmosphere to implementing complex event-driven logic, every phase strengthened our understanding of the Unreal ecosystem.

10) PORTAL ASSIGNMENT USING THREE JS (2026)

# CYBERVERSE — Beyond the Firewall | Interactive First-Person 3D Experience

**Technologies:** JavaScript, Three.js, WebGL, GLSL, Vite, HTML5, CSS3

I developed **CYBERVERSE – Beyond the Firewall**, an interactive, browser-based 3D experience inspired by cybersecurity and digital network environments. The project takes players through two connected worlds: a futuristic Cybersecurity Command Center and an encrypted Cyber Network.

Players explore the command center in first-person view, interact with a robotic guardian using a raycasting-based targeting system, and activate an EMP override to disable it and unlock a glowing digital portal. Walking through the gateway transitions the player into the second world, where they can explore a network environment and return through a matching gateway.

### Key Features & Contributions

- **Procedural 3D Environment Development:** Created two connected 3D worlds using Three.js, generating scene geometry, lighting, server racks, holographic panels, data towers, network nodes, and particles directly through code.
- **First-Person Navigation:** Implemented mouse-based camera controls using the Pointer Lock API, keyboard movement with WASD and arrow keys, sprint functionality, and movement boundaries.
- **Procedural Robot Guardian:** Built an animated robot character from 18 primitive 3D meshes, with independently moving parts, a rotating shoulder ring, scanning head, glowing reactor, and energy shield.
- **Interactive Raycasting:** Implemented a targeting system that detects when the player's crosshair is aimed at the robot within a defined distance, enabling contextual interaction.
- **EMP Override Mechanic:** Developed a staged shutdown sequence featuring robot movement, fading energy effects, shield deactivation, and dynamic status updates to unlock the portal.
- **Live 3D Portal Rendering:** Used WebGLRenderTarget to render the second world into a live texture displayed inside the portal, rather than using a static image.
- **Custom GLSL Shader:** Created a ShaderMaterial-based portal effect with animated energy bands, scan lines, ripple effects, and soft edges.
- **Seamless World Transitions:** Implemented position-based portal crossing detection, animated transition effects, access restrictions while the guardian is active, and a return gateway.
- **HUD and Visual Design:** Designed a futuristic interface with a crosshair, guardian interaction prompt, status indicators, toast notifications, and animated transition overlays.

### Technical Highlights

- Two independently managed Three.js scenes using one WebGL renderer.
- Procedural geometry and animation without external 3D model or texture files.
- Raycaster-based object targeting and interaction.
- Render-to-texture pipeline for live portal previews.
- Custom GLSL fragment shader effects.
- Delta-time-based animation and first-person movement.
- Modular separation of HTML, CSS, and JavaScript project files.

### Learning Outcomes

Through this project, I gained practical experience with real-time 3D rendering in the browser, Three.js scene management, procedural modelling, shader programming, raycasting, animation loops, and interactive first-person environments.
