# AIMANVERSE — Beyond the Portfolio. Into the Experience.

A 3D interactive web portfolio for **Syeda Aiman Munawar** (NED University of Engineering & Technology, CTGA-003).
Visitors enter a cinematic gateway, travel through a real-time 3D world (about, projects, skills, journey, contact),
can play an optional exploration quest, ask a grounded AI assistant about Aiman's work, send her a message, and watch
an After Effects promo. A plain **Classic view** with the same content is always available.

> Every fact on the site comes from Aiman's own CV, project notes and documents. Nothing is invented; where
> information was missing it was left out.

## Features
- **3D world** — React Three Fiber scene, her Blender-made avatar, glowing project islands, skill constellation, 3D year timeline, procedural music (WebAudio, no audio files).
- **Case files** — per-project detail with real footage/screenshots; videos load only when opened.
- **AIMANVERSE Quest World** — a separate, immersive 3D environment (opened from the header; its own lazy-loaded chunk): fly a small drone around a glowing observatory in space with Aiman as your host, and walk up to four meaningful objects to play four unique games — **Portal Tuner** (tune a GLSL-style portal, CYBERVERSE), **Keyframe Rhythm** (drop After Effects keyframes on the beat, clapperboard), **Three-Point Light** (light a head for a director's brief, Blender light rig) and **Retrieval Radar** (choose the right document chunks, the RAG radar dish). Keyboard (WASD/arrows, E, Esc), touch joystick and a Stations list are all supported; a plain list replaces the 3D view if WebGL is unavailable. XP, levels, quests and badges are shown inside Quest only (no pop-ups over the portfolio) and live in the browser's localStorage.
- **Ask Aiman AI** — retrieval-augmented chatbot: answers only from indexed documents, cites sources, refuses when it has no evidence, never reveals personal contact details. See [rag-system/README.md](rag-system/README.md).
- **Contact form** — server-side delivery through Resend with honeypot, fill-time check, rate limit and same-origin protection. See [documentation/CONTACT_SYSTEM.md](documentation/CONTACT_SYSTEM.md).
- **Promo video** — `after-effects/AIMANVERSE_Promo.aep` (editable, generated by ExtendScript) and the rendered MP4, embedded via the "Watch the promo" button.
- **Classic view, CV download, keyboard/reduced-motion support.**

## Run locally
Requires a current LTS release of Node.js (this project was built and tested with `node --version` = v24.21.0).
```powershell
cd frontend
npm install
copy .env.example .env      # then fill in the two keys below
npm run dev                 # http://localhost:5173  (the dev server also serves /api/chat and /api/contact)
```
Keys (both have free tiers; **never commit `.env`**):
| Variable | Purpose | Where to get it |
|---|---|---|
| `GEMINI_API_KEY` | chatbot answers + query embeddings | https://aistudio.google.com/apikey |
| `RESEND_API_KEY` | contact-form email | https://resend.com/api-keys |

Without the keys the site still works: the chatbot falls back to quoting the documents and the form reports that email is not set up.

## Scripts
| Command | What it does |
|---|---|
| `npm run dev` / `npm run build` / `npm run preview` (in `frontend`) | develop / type-check + production build / serve the build |
| `npm run ingest` (in `rag-system`) | rebuild `frontend/api/_rag/index.json` from the sources (needs `GEMINI_API_KEY` for vectors) |
| `npx tsx tests/contact.test.ts` · `mock-gemini.test.ts` · `rag-eval.ts` · `rag-holdout.ts` · `rag-holdout2.ts` (run from `frontend`) | API and RAG tests |

## Deploy (Vercel)
1. Import the repository, set the **Root Directory** to `frontend`.
2. Add environment variables `GEMINI_API_KEY` and `RESEND_API_KEY` (Production).
3. Deploy. `vercel.json` already bundles the RAG index into the chat function and serves the CV as a download.
4. After deploy, verify on the live URL: CV download, chat answer, contact email, promo video.
(Deployment status: see `PROJECT_LOG.md`.)
